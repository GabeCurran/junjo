# @junjo/docs

Documentation site for Junjo, live at [docs.junjo.io](https://docs.junjo.io). Built with [Nextra](https://nextra.site) on Next.js; content lives under `pages/` as MDX (getting started, tutorial, SDK and React references, auth adapter guides, the HTTP API reference, and the self-hosting guide). Locally it runs on `http://localhost:3001` as part of the repo-root `npm run dev`, or standalone via `npm run dev -w @junjo/docs`. Deployed on Railway from the repo's root Dockerfile with `WORKSPACE=docs`.
