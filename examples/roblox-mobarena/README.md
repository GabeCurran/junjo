# Example: Roblox MOBArena

Pointer to the dogfood target for the Junjo.io SDK for Roblox (`packages/sdk-roblox`). The actual game lives in the separate `mobarena-roblox` repo. This directory will host a copy of the Junjo-integration code (or a `git submodule` link) once that integration exists. The SDK itself is now feature-complete for server-side use (groups, members, roles, invitations, audit, webhooks endpoint CRUD, bans, and friends), so the integration is no longer blocked on SDK surface.
